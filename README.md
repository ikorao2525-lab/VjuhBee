# BeeCalc

BeeCalc — офлайн-помощник пчеловода для Android.

Приложение помогает:
- рассчитывать сироп;
- вести календарь работ по годам;
- хранить ульи, осмотры и обработки;
- связывать работы с несколькими ульями;
- создавать QR-коды ульев и импортировать их;
- экспортировать и импортировать всю пасеку JSON-файлом;
- формировать отчёты и сохранять их в PDF;
- открывать профиль улья и быстрый отчёт по выбранному улью;
- видеть на главной странице ближайшие и просроченные работы;
- при первом запуске выбрать пустую пасеку или загрузить демонстрационные данные;
- учитывать несколько видов продукции и единицы измерения;
- использовать каталог калькуляторов: сироп, канди, обработка пасеки, планирование отводков, зимние запасы корма и банки мёда;
- быстро отмечать работы выполненными прямо на главной странице;
- сворачивать длинные секции работ на главной странице;
- искать и фильтровать работы в календаре.

## Принцип работы

BeeCalc работает по принципу offline-first: основные данные хранятся локально в Room, обязательное подключение к интернету не требуется.

## Сборка в Windows 11

Требуются Android Studio с JBR/JDK и Android SDK.

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
$env:ANDROID_HOME = "C:\Users\jukle\AppData\Local\Android\Sdk"
.\gradlew.bat :app:assembleBetaDebug
```

APK:

`app/build/outputs/apk/beta/debug/app-beta-debug.apk`

Для личной рассылки тестерам APK можно переименовать в `BeeCalc_v0.8.7-alpha-test.apk`.

Исходный файл Gradle: `app/build/outputs/apk/beta/debug/app-beta-debug.apk`

Установка через ADB:

```powershell
& "$env:ANDROID_HOME\platform-tools\adb.exe" install -r --no-streaming app\build\outputs\apk\beta\debug\app-beta-debug.apk
```

## Основные функции

### Календарь

Работы распределены по годам и месяцам. Выполненные работы сохраняются в архиве. Работу можно связать с одним или несколькими ульями. Для работы можно указать точную дату выполнения; старые работы без даты сохраняют отображение по месяцу. Для заданных дат показываются статусы «скоро», «просрочено» и «критично».

### Учёт продукции

Урожай хранится отдельными позициями внутри работы:

- мёд — кг или л;
- пыльца, перга, воск, забрус, мерва и подмор — кг;
- прополис, маточное молочко и пчелиный яд — г;
- матки, отводки и пчелопакеты — шт.

В редакторе продукция выбирается через выпадающее меню, а единицы отображаются на русском языке. Отчёты группируют данные по месяцам. Интерфейс использует увеличенные контрастные кнопки для работы на улице и в перчатках.

### Синхронизация

Пасека переносится JSON-файлом. В резервной копии сохраняются ульи, календарные работы, урожай, осмотры, обработки и связи «улей ↔ работы» через UUID. Импорт выполняется локально, с проверкой файла, резервной копией и разбором новых данных и конфликтов. Экспорт содержит метаданные версии приложения и состава данных; последний импорт можно отменить через созданную перед ним копию.

### Отчёты

Доступны плавающие периоды, произвольный диапазон, отчёт по улью или всей пасеке. Отчёт включает работы, осмотры, обработки и собранную продукцию. Месяцы выделяются отдельными блоками. PDF поддерживает несколько страниц, его можно поделиться, сохранить на устройство или открыть для печати.
